# Instructions

1. Run ```python save_parquet_chunks.py``` to convert yearly csv file into chunks of parquet files. 
2. Run ```python combine_chunks.py``` to combine chunks into one parquet file.
3. Run ```python generate_yield_geotiffs.py``` to generate yield geotiffs for each field. 
4. Run ```python process_all.py``` to process all modalities' data.
